AI Resume Pro V13

Mobile offline: open index.html. All V12 features work; the Real AI button needs a server.

Laptop online AI: install Python 3, set OPENAI_API_KEY as an environment variable, run python3 server.py inside this folder and open http://localhost:8000. Provider API usage may cost money. Do not share your API key.

This is a development demo, not a publicly deployable production server. Before public launch add login/auth, rate limiting, consent/privacy policy, HTTPS and payment security.
